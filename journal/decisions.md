# decisions — 資料に書かれていない点をどう解釈したか

> エージェントが追記する。消さない。
> 数値が再現しない時、**最初に疑う場所の一覧**になる。

書式：

```markdown
## D<番号>: <短い題>
- 題材: <名前>
- 資料の記述: <何と書いてあるか。書いていないなら「記述なし」>
- 選んだもの: <値や方式>
- 根拠: <なぜそれを選んだか>
- 影響する主張: <C番号>
- 状態: 未確定 / 確定（<確定した理由>）
```

---

## D1: 1/5 成功則の定数 c
- 題材: example_es
- 資料の記述: 3章で「0.817 ≤ c < 1 の範囲で選ぶ」とだけあり、5章の実験で使った値は記述なし
- 選んだもの: 0.85
- 根拠: 範囲の中で下寄りの値。範囲内ならどれでも C1 の向きは変わらない（テストで確認）
- 影響する主張: C3
- 状態: 未確定（C3 が合わなければ最初に疑う）

## D2: 成功率を数える窓 w の区切り方
- 題材: example_es
- 資料の記述: 「w 世代ごとに」とあるが、窓が重なるか（移動平均か）の記述なし
- 選んだもの: 重ならない窓（w 世代ごとにリセット）
- 根拠: 「w 世代ごとに更新」という文言に最も素直な解釈
- 影響する主張: C3
- 状態: 未確定
