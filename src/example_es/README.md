# example_es の実装

## 記号とコード名の対応表（ユビキタス言語）

| 論文の記号 | コード上の名前 | 意味 | 出典 |
| --- | --- | --- | --- |
| $x$ | `x` | 親（現在の解） | 式(1) |
| $y$ | `y` | 子 | 式(1) |
| $\sigma$ | `sigma` | ステップサイズ | 式(1)(2) |
| $\sigma_0$ | `sigma0` | 初期ステップサイズ | 2章 |
| $p_s$ | `success_rate` | 直近 $w$ 世代の成功率 | 式(2) |
| $c$ | `c` | ステップサイズの縮小率 | 式(2) |
| $w$ | `window` | 成功率を数える世代数 | 2章 |

## 層

* `core/`：`step_size.py`（式(2)）、`objectives.py`（式(3)）。乱数も入出力も持たない
* `algorithm/`：`es.py`（アルゴリズム1）。乱数はここで `random.Random(seed)` として作る

## この題材の注意点

* 成功の判定は `<=`（等号を含む）。`<` にすると平坦な領域で成功率が下がり、σ が縮みすぎる
